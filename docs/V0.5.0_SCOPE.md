# FlipFit v0.5.0

This release closes the unfolded-workout control gap introduced by the v0.4 visual redesign.

## Unfolded workout parity
- Persistent LIST and ⋮ controls while a workout is active.
- Skip current set / remaining exercise.
- Add or remove planned sets.
- Add, replace, and reorder session exercises.
- Undo last accounted set.
- Finish with explicit confirmation.
- Searchable exercise picker.
- Tappable workout overview for jumping between exercises.

The cover-screen implementation is intentionally unchanged.
