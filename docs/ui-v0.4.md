# FlipFit v0.4 UI direction

- Restrained black/charcoal base with lime accent.
- Soft glass-like surfaces with fine outlines rather than heavy effects.
- Bottom navigation on the unfolded app: Home, Exercises, Templates, History.
- Home focuses on quick start, last workout, and a small template preview.
- Settings move into a compact dialog.
- PRs remain available inside History.
- Cover-screen workout stays minimal, high-contrast, and feature-complete.
- No workout functionality removed as part of the redesign.
